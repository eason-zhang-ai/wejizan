# 产品说明

## 1. 产品定位

“伪集赞”是一个朋友圈界面创作工具，用于娱乐、教学、活动排版和 UI 原型。用户可以生成带指定文案、图片、点赞昵称和评论的朋友圈画面，或在已有朋友圈截图上补充互动区域。

产品不是社交平台，不发布朋友圈、不连接微信账号，也不在服务端保存用户草稿。默认水印和关闭水印前的用途提示属于产品安全边界。

## 2. 核心工作流

### 2.1 生成模式

用户提供或编辑：

- 朋友圈作者昵称和头像
- 最多 2000 字文案
- 1–9 张产品或内容图片
- 最多 100 个点赞昵称，可批量精确输入
- 最多 8 条评论，可逐条编辑作者与正文
- iOS 或 Android 设备模板
- 朋友圈主人昵称、头像和封面
- 陪衬信息流的顺序、显示状态和随机内容
- 状态栏组件、位置、显示值和缩放

应用在完整手机画面中渲染微信朋友圈，包括状态栏、导航、封面、主人信息、朋友圈内容、点赞和评论。用户在手机内部纵向浏览，并导出当前手机视口。

### 2.2 截图叠加模式

用户上传一张朋友圈截图，然后：

- 设置点赞人数或精确昵称
- 设置最多 8 条评论
- 在手机画面中 1:1 拖动互动块
- 调整互动块宽度
- 可选用自定义状态栏覆盖原图状态栏
- 导出不含编辑辅助框的当前画面

当前实现是在原图上新增互动块，不会自动识别或擦除原图已有的点赞和评论。

## 3. 编辑器体验

- 顶部切换生成/叠加模式和 iOS/Android。
- 左侧检查器包含内容、信息流、状态栏和 AI 四个页签。
- 中间为实时手机预览；生成模式可滚动，叠加模式可拖动互动块。
- 右侧显示导出检查摘要。
- 草稿在本机自动保存，页面刷新后恢复。
- 默认显示“模拟生成 · 伪集赞”水印；关闭前弹出用途警告。
- H5 导出 3× PNG；微信小程序保存到相册。

## 4. AI 能力

AI 是可选的用户自带密钥能力：

- 对当前朋友圈文案返回自然、促销和简洁三种版本。
- 根据当前文案生成指定数量的自然评论。
- 用户在 AI 页签保存 OpenAI 兼容 API 地址、API Key 与模型名，配置只保存在当前设备。
- 用户文案会直接发送到其选择的 AI 服务；应用不提供默认 Key、访问口令、短期令牌或调用限流。

AI 服务兼容 OpenAI 风格的 `/v1/chat/completions` 接口。H5 上游须允许 CORS，微信小程序上游须配置为请求合法域名。用户图片与文案不写入本项目服务器；文案会在用户调用时传给其所配置的上游服务，上线前需要在隐私说明中明确这一点。

## 5. 当前 MVP 状态

| 能力 | 状态 | 说明 |
|---|---|---|
| 完整朋友圈手机预览 | 已实现 | iOS/Android、封面、导航、信息流、互动区 |
| 生成模式 | 已实现 | 图片、文案、点赞、评论、身份编辑 |
| 截图叠加模式 | 已实现 | 上传、拖动、宽度、状态栏覆盖 |
| 陪衬朋友圈 | 已实现 | 默认 4 条，可重抽、隐藏、上下排序 |
| 状态栏编辑 | 已实现 | 11 类组件，拖放、值、缩放和显隐 |
| 本地草稿 | 已实现 | Taro 同步 Storage，单草稿 |
| H5 导出 | 已实现 | 隐藏画布 + `html-to-image`，3× PNG |
| 微信小程序导出 | 已实现但需视觉校准 | Canvas 近似绘制，与 H5 DOM 不是同一渲染路径 |
| AI 润色/评论 | 已实现 | 用户在本机配置兼容 AI 服务后直连 |
| 静态部署/GitHub Actions | 已实现配置 | H5 可发布到任意支持 SPA fallback 的静态托管 |
| 端到端视觉测试 | 未实现 | 当前只有核心逻辑和服务端接口测试 |

## 6. 产品边界与非目标

- 不连接微信、不代替真实点赞、不自动发布或传播截图。
- 不提供批量造假、用户身份仿冒、交易证明或绕过水印提示的自动化。
- MVP 不提供账号系统、云端草稿、多用户协作、支付、模板市场或运营后台。
- MVP 不保证任意微信版本和所有手机分辨率的像素级一致；需要通过模板版本化逐步完善。

## 7. 建议的下一阶段

### P0：建立可评审基线

1. 在真实浏览器完成桌面端和窄屏视觉走查。
2. 在微信开发者工具检查触摸拖动、图片选择、Canvas 导出和相册权限。
3. 使用具备 CORS 的测试 AI 服务验证 H5 直连，并在微信开发者工具验证请求合法域名。
4. 确认当前 MVP 后创建首个 Git 提交与版本标签。

### P1：提升可靠性

1. 将 H5 图片与草稿迁移到 IndexedDB，避免 base64 超出 localStorage 配额。
2. 为 `schemaVersion` 增加草稿迁移框架。
3. 增加 Playwright 视觉/交互测试和截图基线。
4. 统一 H5 与微信小程序的截图布局算法，减少两条渲染路径的差异。
5. 对上传截图使用等比适配和可编辑裁切，避免 `aspectFill` 意外裁边。

### P2：增强编辑能力

1. 增加时间、位置、封面裁切和图片裁切编辑。
2. 保存、复制和切换状态栏方案。
3. 提供更丰富但可审查的头像素材和朋友圈模板。
4. 增加导出前检查，包括溢出、空内容、评论截断和水印状态。
